# Capas das faixas

Adiciona uma imagem JPG, PNG ou WebP por faixa, usando o mesmo nome do MP3. Por exemplo:

- `imagens/capas/so-close-to-what/miss-possessive.jpg`
- `imagens/capas/think-later/cut-my-hair.jpg`
- `imagens/capas/i-used-to-think-i-could-fly/dont-come-back.jpg`

A capa da faixa selecionada aparece sobre o vinil. Usa imagens que tenhas direito a incluir no projeto.
